# Kelly Lachance — Portfolio V2
Portfolio statique responsive. Le contenu est séparé du design.

- `index.html` : structure et design (à ne modifier que pour changer l'apparence)
- `content.js` : textes, projets, compétences, liens (fichier de modification courant)
- `assets/` : photo, images de projets, CV
- `GUIDE_MODIFICATIONS.md` : guide pas à pas

Prévisualisation : ouvrir `index.html` dans un navigateur.
Publication : GitHub Pages (Settings → Pages → Deploy from branch → main / root).
